# Кадр — бесплатный фоторедактор с ИИ в браузере

Редактор фото, который работает прямо в браузере, на компьютере и на телефоне.
Фото никуда не загружается: вся обработка происходит на устройстве пользователя.
Не нужны ни регистрация, ни свой сервер, на фото не появляется водяной знак.

## Что умеет

- **Фильтры:** 12 фильтров с регулировкой силы.
- **Настройки:** экспозиция, яркость, контраст, светлые участки и тени, насыщенность,
  теплота, оттенок, выцветание, резкость, зерно, размытие, виньетка и автоулучшение.
- **Обрезка:** свободная или под соцсети (1:1, 4:5, 9:16, 16:9), поворот, отражение
  и наклон для выравнивания горизонта.
- **ИИ-ластик:** закрасьте лишнее, и ИИ дорисует то, что было за ним.
- **Удаление фона:** прозрачный, цветной или размытый фон.
- **Текст:** 8 шрифтов с русскими буквами, обводка, тень, плашка и поворот.
- **Стикеры:** больше 50 эмодзи, их можно двигать, увеличивать и поворачивать.
- **Рисунок:** кисть любого цвета и толщины.
- **Рамки:** обычные и полароидные, скругление углов.
- Отмена и повтор действий, сравнение «до и после», сохранение в JPG или PNG.

## Из чего состоит проект

| Файл | Что в нём |
|---|---|
| `index.html` | Главная страница (заставка) с примерами |
| `landing.css`, `landing.js` | Оформление главной страницы и ползунки «до и после» |
| `editor.html` | Сам редактор |
| `style.css` | Общий внешний вид: цвета, шрифты, кнопки, версия для телефона |
| `script.js` | Вся логика редактора |
| `examples/` | Фото для примеров на главной странице |
| `fonts/` | Шрифты с поддержкой русского языка |

## Как проверить на своём компьютере

Откройте файл `index.html` двойным щелчком: откроется главная страница,
а с неё можно перейти в редактор. Для обычных функций интернет не нужен.
ИИ-ластику и удалению фона интернет нужен один раз, чтобы скачать модель.

## Как обновить сайт на GitHub

1. Откройте свой репозиторий на GitHub.
2. Нажмите **Add file → Upload files**.
3. Откройте папку проекта, выделите всё внутри (Ctrl+A) и перетащите в окно браузера.
   Файлы с теми же названиями заменятся новыми, а новые файлы и папки добавятся.
4. Нажмите **Commit changes**.
5. Через одну-две минуты обновите сайт. Если видна старая версия,
   нажмите Ctrl+F5, чтобы браузер загрузил всё заново.

## Как работает ИИ

ИИ-инструменты работают прямо в браузере через библиотеку
[ONNX Runtime Web](https://onnxruntime.ai/). При первом запуске браузер скачивает модель:

- ИИ-ластик: [MI-GAN](https://github.com/Picsart-AI-Research/MI-GAN) от Picsart AI Research,
  около 28 МБ, лицензия MIT;
- удаление фона: [ORMBG](https://huggingface.co/onnx-community/ormbg-ONNX), около 44 МБ,
  лицензия Apache 2.0.

Модели загружаются с Hugging Face, библиотека — с jsDelivr. После первой загрузки
браузер их запоминает. Само фото при этом никуда не отправляется.

Обе модели обучены на наборе фотографий Places2, условия которого рассчитаны
на некоммерческое использование. Для бесплатного сайта это нормально. Если решите
зарабатывать на сайте, сначала уточните этот вопрос.

## Как поменять под себя

- **Название.** Замените слово «Кадр» в `index.html` и `editor.html`.
- **Цвета.** Все цвета собраны в начале файла `style.css` в блоке `:root`.
  Например, `--accent` отвечает за жёлтый цвет кнопок.
- **Фильтры.** Список лежит в начале `script.js` в массиве `FILTERS`.
  Скопируйте любую строку, поменяйте название и числа, и получится новый фильтр.
- **Стикеры.** Список эмодзи лежит в массиве `STICKERS` в `script.js`.
