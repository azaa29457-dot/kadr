# Кадр — бесплатный фоторедактор в браузере

Редактор фото, который работает прямо в браузере, на компьютере и на телефоне.
Фото никуда не загружается: вся обработка происходит на устройстве пользователя.
Не нужны ни регистрация, ни сервер, на фото не появляется водяной знак.

## Что умеет

- открывать фото кнопкой, перетаскиванием файла или вставкой из буфера обмена (Ctrl+V);
- 12 фильтров с регулировкой силы;
- менять яркость, контраст, насыщенность и теплоту, добавлять размытие и виньетку;
- обрезать фото свободно или под соцсети (1:1, 4:5, 9:16, 16:9), поворачивать и отражать;
- добавлять надписи: 8 шрифтов, любой цвет, обводка, тень или плашка, надпись можно перетаскивать;
- отменять и повторять действия (Ctrl+Z и Ctrl+Shift+Z);
- сравнивать с оригиналом: зажмите кнопку «До и после»;
- сохранять в JPG или PNG в полном размере, а на телефоне ещё и делиться через меню «Поделиться».

## Как проверить на своём компьютере

Откройте файл `index.html` двойным щелчком, и редактор откроется в браузере.
Интернет для этого не нужен.

## Как выложить на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Придумайте название, например `kadr`. Оставьте вариант **Public** и нажмите **Create repository**.
4. На странице репозитория нажмите ссылку **uploading an existing file**
   (или **Add file → Upload files**).
5. Откройте папку проекта и перетащите в окно браузера **всё её содержимое**:
   `index.html`, `style.css`, `script.js`, `README.md` и папку `fonts`.
   Важно: перетаскивайте файлы, а не саму папку проекта, иначе сайт не откроется по основной ссылке.
6. Внизу нажмите **Commit changes** и дождитесь окончания загрузки.
7. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите
   **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
8. Подождите одну-две минуты и обновите страницу. Вверху появится ссылка на сайт вида
   `https://ваше-имя.github.io/kadr/`.

Чтобы обновить сайт, снова загрузите изменённые файлы с теми же названиями через
**Add file → Upload files**. Через минуту изменения появятся на сайте.

## Из чего состоит проект

| Файл | Что в нём |
|---|---|
| `index.html` | Разметка страницы: кнопки, панели, окно сохранения |
| `style.css` | Внешний вид: цвета, шрифты, расположение, версия для телефона |
| `script.js` | Вся логика: фильтры, обрезка, текст, отмена действий, сохранение |
| `fonts/` | Шрифты с поддержкой русского языка |

## Как поменять под себя

- **Название.** Замените слово «Кадр» в `index.html`: в теге `<title>` и в блоке `brand-name`.
- **Цвета.** Все цвета собраны в начале файла `style.css` в блоке `:root`.
  Например, `--accent` отвечает за жёлтый цвет кнопок.
- **Фильтры.** Список фильтров лежит в начале `script.js` в массиве `FILTERS`.
  Каждый фильтр — это набор значений: яркость, контраст, насыщенность и другие.
  Скопируйте любую строку, поменяйте название и числа, и получится новый фильтр.
